API de consulta v1

Use HTTPS e o cabeçalho Authorization: Bearer SEU_TOKEN. A API aceita apenas GET, retorna JSON e limita cada token a 60 consultas por minuto. Listas têm 50 registros por página com ?pagina=2. O identificador de empresa sempre é aplicado pelo servidor; contas Master informam ?empresa=ID para consultar uma empresa.

{% if endpoints %}Exemplo: GET /api/v1/{{ endpoints.0.key }}/ ou GET /api/v1/{{ endpoints.0.key }}/42/. {% endif %}O token é pessoal, expira e perde o acesso quando a permissão, o vínculo ou a situação da conta muda. Não coloque o token em URLs, aplicativos públicos ou repositórios.

Atendimento comercial do WhatsApp Master

O fluxo apresenta planos públicos ativos com preços cadastrados, responde dúvidas sobre o sistema e coleta nome, empresa, segmento, e-mail, unidades, profissionais, plano de interesse e necessidade. Os dados são salvos progressivamente no funil Comercial e vinculados à conversa. A equipe recebe o histórico ao final; o cliente também pode solicitar uma pessoa imediatamente.

O bloco Dúvidas do ApPlanner consulta a base de orientações do sistema, sem depender de IA. O bloco Cadastro automático de lead permite responder dúvidas durante a coleta. Não é concedido consentimento de marketing automaticamente. E-mail inválido e quantidades incorretas são solicitados novamente.

Edite e simule em Construtor do chatbot. O simulador não grava leads nem envia mensagens. O atendimento real exige automação habilitada, gateway conectado e worker/beat funcionando.

Use GET /api/v1/leads/ e /api/v1/leads/ID/ com commercial.read para consultar os dados. O comercial consulta apenas leads atribuídos a ele. /api/v1/planos-publicos/ expõe planos públicos ativos; /api/v1/chatbot-master/ exige master.read e retorna indicadores sem credenciais ou mensagens privadas.
