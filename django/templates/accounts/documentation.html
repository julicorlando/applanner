API de consulta v1

Use HTTPS e o cabeçalho Authorization: Bearer SEU_TOKEN. A API aceita apenas GET, retorna JSON e limita cada token a 60 consultas por minuto. Listas têm 50 registros por página com ?pagina=2. O identificador de empresa sempre é aplicado pelo servidor; contas Master informam ?empresa=ID para consultar uma empresa.

{% if endpoints %}Exemplo: GET /api/v1/{{ endpoints.0.key }}/ ou GET /api/v1/{{ endpoints.0.key }}/42/. {% endif %}O token é pessoal, expira e perde o acesso quando a permissão, o vínculo ou a situação da conta muda. Não coloque o token em URLs, aplicativos públicos ou repositórios.
